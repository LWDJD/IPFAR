## ⚠️ 使用声明与设计初衷

本项目是一个去中心化的数据存储协议桥接工具，旨在促进**珍贵数据的长期保存与全球可访问性**。

### 适用范围
本软件作为**高效数据传输基础设施**，专为以下合法用途设计：
1. **公共数据的长期备份**：如政府公开文档、科研数据集、历史档案。
2. **个人数字资产的永存**：用户自主创作的、拥有完整版权的作品。
3. **高效数据分发基础设施**：利用去中心化网络的特性，为公开访问的数字资产提供兼具经济性与高可用性的内容路由与分发支持，降低合法数据的传播门槛。
