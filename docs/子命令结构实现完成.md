## 🔧 代码结构

### Command 结构体
```go
type Command struct {
    Name        string                    // 命令名称
    Short       string                    // 简短描述
    Long        string                    // 详细描述
    Usage       string                    // 使用说明
    Args        int                       // 参数数量要求
    Run         func(args []string) error // 执行函数
    Flags       func()                    // 注册标志的函数
    Hidden      bool                      // 是否在帮助中隐藏
    Subcommands []*Command                // 子命令
}
```

### 添加新命令
```go
// 简单命令
RootCommand.AddCommand(&Command{
    Name:  "mycommand",
    Short: "我的命令",
    Run: func(args []string) error {
        fmt.Println("执行我的命令")
        return nil
    },
})

// 带子命令的命令
parentCmd := &Command{
    Name:  "parent",
    Short: "父命令",
}

parentCmd.AddCommand(&Command{
    Name:  "child",
    Short: "子命令",
    Run: func(args []string) error {
        fmt.Println("执行子命令")
        return nil
    },
})

RootCommand.AddCommand(parentCmd)
```
