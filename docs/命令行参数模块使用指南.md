# 命令行参数模块使用指南

## 📖 概述

`flags` 模块提供了一个强大且易用的命令行参数解析工具，支持：

- ✅ 定义字符串、布尔、整数等类型的参数
- ✅ 支持必需参数和可选参数
- ✅ 自定义参数验证
- ✅ 自动生成帮助信息
- ✅ 支持短参数名称（如 `-n`）
- ✅ 参数是否设置的检测

## 🚀 快速开始

### 基本使用

```go
package main

import (
    "fmt"
    "os"
    "github.com/lwdjd/IPFAR/internal/flags"
)

func main() {
    // 1. 创建参数集合
    fs := flags.NewFlagSet("myapp")
    
    // 2. 定义参数
    fs.DefineString("name", "n", "World", "要问候的名字", false)
    fs.DefineBool("verbose", "v", false, "启用详细输出")
    fs.DefineInt("port", "p", 8080, "服务端口号", false)
    
    // 3. 解析参数
    if err := fs.Parse(); err != nil {
        fmt.Fprintf(os.Stderr, "错误：%v\n", err)
        os.Exit(1)
    }
    
    // 4. 获取参数值
    name := fs.GetString("name")
    verbose := fs.GetBool("verbose")
    port := fs.GetInt("port")
    
    fmt.Printf("Hello, %s! Port: %d, Verbose: %v\n", name, port, verbose)
}
```

### 运行示例

```bash
# 使用默认值
./myapp

# 指定参数
./myapp -name Alice -port 9000 -v

# 使用短参数
./myapp -n Bob -p 3000

# 查看帮助
./myapp -h
```

## 📋 参数定义方法

### 1. DefineString - 字符串参数

```go
fs.DefineString("config", "c", "config.json", "配置文件路径", false)
```

**参数说明：**
- `name`: 参数长名称（如 `-config`）
- `short`: 参数短名称（如 `-c`），可为空
- `defaultValue`: 默认值
- `usage`: 使用说明
- `required`: 是否必需

### 2. DefineBool - 布尔参数

```go
fs.DefineBool("verbose", "v", false, "启用详细模式")
```

**特点：**
- 不需要传值，出现即表示 `true`
- 默认值通常为 `false`

### 3. DefineInt - 整数参数

```go
fs.DefineInt("port", "p", 8080, "服务端口号")
```

### 4. Define - 高级定义（支持验证）

```go
fs.Define(flags.Flag{
    Name:     "email",
    Short:    "e",
    Value:    "",
    Usage:    "用户邮箱",
    Required: true,
    ValidateFunc: func(value string) error {
        if !strings.Contains(value, "@") {
            return fmt.Errorf("邮箱格式不正确")
        }
        return nil
    },
})
```

## 🔍 内置验证函数

### ValidateNotEmpty - 非空验证

```go
fs.Define(flags.Flag{
    Name:     "username",
    Value:    "",
    Usage:    "用户名",
    Required: true,
    ValidateFunc: flags.ValidateNotEmpty,
})
```

### ValidateFilePath - 文件路径验证

```go
fs.Define(flags.Flag{
    Name:     "config",
    Value:    "config.json",
    Usage:    "配置文件",
    ValidateFunc: flags.ValidateFilePath,
})
```

**功能：**
- 检查路径是否为空
- 检查文件是否存在

### ValidateDirPath - 目录路径验证

```go
fs.Define(flags.Flag{
    Name:     "output-dir",
    Value:    "./output",
    Usage:    "输出目录",
    ValidateFunc: flags.ValidateDirPath,
})
```

**功能：**
- 检查路径是否为空
- 检查目录是否存在
- 检查是否为目录（不是文件）

### ValidateNumber - 数字范围验证

```go
// 验证端口号（1-65535）
fs.Define(flags.Flag{
    Name:  "port",
    Value: "8080",
    Usage: "端口号",
    ValidateFunc: flags.ValidateNumber(1, 65535),
})

// 验证数量（1-100）
fs.Define(flags.Flag{
    Name:  "count",
    Value: "10",
    Usage: "数量",
    ValidateFunc: flags.ValidateNumber(1, 100),
})
```

### 自定义验证函数

```go
fs.Define(flags.Flag{
    Name:  "level",
    Value: "info",
    Usage: "日志级别",
    ValidateFunc: func(value string) error {
        validLevels := []string{"debug", "info", "warn", "error"}
        for _, level := range validLevels {
            if value == level {
                return nil
            }
        }
        return fmt.Errorf("无效的日志级别：%s", value)
    },
})
```

## 📖 获取参数值

### GetString - 获取字符串

```go
name := fs.GetString("name")
config := fs.GetString("config")
```

### GetBool - 获取布尔值

```go
verbose := fs.GetBool("verbose")
debug := fs.GetBool("debug")
```

**支持的值：**
- `true`, `1`, `yes` → `true`
- 其他 → `false`

### GetInt - 获取整数

```go
port := fs.GetInt("port")
count := fs.GetInt("count")
```

### IsSet - 检查参数是否被设置

```go
if fs.IsSet("config") {
    fmt.Println("用户指定了配置文件")
} else {
    fmt.Println("使用默认配置文件")
}
```

## 🎯 完整示例

### 示例 1：简单的文件处理工具

```go
package main

import (
    "fmt"
    "os"
    "github.com/lwdjd/IPFAR/internal/flags"
)

func main() {
    fs := flags.NewFlagSet("filetool")
    
    fs.Define(flags.Flag{
        Name:     "input",
        Short:    "i",
        Value:    "",
        Usage:    "输入文件路径",
        Required: true,
        ValidateFunc: flags.ValidateFilePath,
    })
    
    fs.Define(flags.Flag{
        Name:     "output",
        Short:    "o",
        Value:    "",
        Usage:    "输出文件路径",
        Required: true,
    })
    
    fs.DefineBool("compress", "c", false, "压缩输出")
    fs.DefineInt("level", "l", 6, "压缩级别（1-9）", false)
    
    if err := fs.Parse(); err != nil {
        fmt.Fprintf(os.Stderr, "错误：%v\n", err)
        os.Exit(1)
    }
    
    inputFile := fs.GetString("input")
    outputFile := fs.GetString("output")
    compress := fs.GetBool("compress")
    level := fs.GetInt("level")
    
    fmt.Printf("输入：%s\n", inputFile)
    fmt.Printf("输出：%s\n", outputFile)
    fmt.Printf("压缩：%v (级别：%d)\n", compress, level)
}
```

### 示例 2：服务器配置

```go
package main

import (
    "fmt"
    "os"
    "github.com/lwdjd/IPFAR/internal/flags"
)

func main() {
    fs := flags.NewFlagSet("server")
    
    fs.DefineInt("port", "p", 8080, "HTTP 端口", false)
    fs.DefineString("host", "", "0.0.0.0", "监听地址", false)
    fs.DefineString("config", "c", "config.yaml", "配置文件", false)
    fs.DefineBool("debug", "d", false, "调试模式", false)
    fs.DefineBool("https", "", false, "启用 HTTPS", false)
    
    fs.Define(flags.Flag{
        Name:  "workers",
        Value: "4",
        Usage: "工作线程数",
        ValidateFunc: flags.ValidateNumber(1, 32),
    })
    
    if err := fs.Parse(); err != nil {
        fmt.Fprintf(os.Stderr, "错误：%v\n", err)
        os.Exit(1)
    }
    
    fmt.Printf("服务器配置:\n")
    fmt.Printf("  地址：%s:%d\n", 
        fs.GetString("host"), 
        fs.GetInt("port"))
    fmt.Printf("  调试：%v\n", fs.GetBool("debug"))
    fmt.Printf("  HTTPS: %v\n", fs.GetBool("https"))
    fmt.Printf("  工作线程：%d\n", fs.GetInt("workers"))
    
    if fs.IsSet("config") {
        fmt.Printf("  配置文件：%s\n", fs.GetString("config"))
    }
}
```

### 自定义帮助信息

```go
fs := flags.NewFlagSet("myapp")

// 可以在定义参数后自定义帮助信息的显示
```

### 处理参数冲突

```go
fs.DefineBool("json", "", false, "JSON 格式输出")
fs.DefineBool("xml", "", false, "XML 格式输出")

if err := fs.Parse(); err != nil {
    fmt.Fprintf(os.Stderr, "错误：%v\n", err)
    os.Exit(1)
}

if fs.GetBool("json") && fs.GetBool("xml") {
    fmt.Fprintln(os.Stderr, "错误：不能同时使用 JSON 和 XML 格式")
    os.Exit(1)
}
```

### 处理依赖参数

```go
fs.DefineBool("https", "", false, "启用 HTTPS")
fs.DefineString("cert", "", "", "SSL 证书文件")
fs.DefineString("key", "", "", "SSL 私钥文件")

if err := fs.Parse(); err != nil {
    fmt.Fprintf(os.Stderr, "错误：%v\n", err)
    os.Exit(1)
}

if fs.GetBool("https") {
    if fs.GetString("cert") == "" || fs.GetString("key") == "" {
        fmt.Fprintln(os.Stderr, "错误：启用 HTTPS 必须指定证书和私钥")
        os.Exit(1)
    }
}
```

## 📊 最佳实践

### 1. 使用有意义的默认值

```go
// ✅ 好的默认值
fs.DefineInt("port", "p", 8080, "端口号", false)

// ❌ 避免空默认值
fs.DefineInt("port", "p", 0, "端口号", false)
```

### 2. 为必需参数添加验证

```go
fs.Define(flags.Flag{
    Name:     "config",
    Required: true,
    ValidateFunc: flags.ValidateFilePath,
})
```

```go
if err := fs.Parse(); err != nil {
```

## 📝 注意事项

1. **参数命名**：使用小写字母和连字符（如 `output-file`）
2. **短参数**：通常为单个字母（如 `-v`, `-h`, `-p`）
3. **必需参数**：尽量少用，避免降低易用性
4. **验证函数**：在定义时添加，提前捕获错误
5. **帮助信息**：确保使用说明清晰准确
