log.Error("错误信息")

## 🎯 关于全局变量的说明

当前项目使用全局变量（`ConfigFile`, `Loc`）是合理的，因为：

1. **项目早期阶段** - 快速迭代优先
2. **配置单例性** - 配置文件本身就应该是全局唯一的
3. **语言实例单例性** - 翻译资源也应该是全局共享的

**当前实现的安全性：**
- 在 `init()` 中初始化，保证只执行一次
- 启动时加载，之后只读访问
- 简单直接，适合早期开发

**未来重构建议（项目中后期）：**
```go
// 使用依赖注入
type App struct {
    config *Config
    locale *gotext.Locale
    logger *log.Logger
}

func NewApp() (*App, error) {
    // 初始化逻辑
}
```
