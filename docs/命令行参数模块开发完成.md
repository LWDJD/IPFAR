# 命令行参数模块开发完成

## ✅ 功能特性

已成功创建一个功能完整的命令行参数解析模块 `internal/flags`，支持：

### 核心功能
- ✅ **参数定义** - 支持字符串、布尔、整数三种类型
- ✅ **参数解析** - 自动解析命令行参数
- ✅ **帮助信息** - 自动生成格式化的帮助文档
- ✅ **短参数支持** - 支持 `-n` 和 `--name` 两种形式
- ✅ **必需参数** - 支持标记必需参数
- ✅ **参数验证** - 内置多种验证函数，支持自定义验证
- ✅ **参数检测** - 可检测参数是否被用户设置

### 参数类型

#### 1. 字符串参数
```go
fs.DefineString("name", "n", "default", "使用说明", false)
```

#### 2. 布尔参数
```go
fs.DefineBool("verbose", "v", false, "启用详细模式")
```

#### 3. 整数参数
```go
fs.DefineInt("port", "p", 8080, "服务端口号")
```

#### 4. 高级定义（带验证）
```go
fs.Define(Flag{
    Name:     "config",
    Short:    "c",
    Value:    "config.json",
    Usage:    "配置文件路径",
    Required: true,
    ValidateFunc: flags.ValidateFilePath,
})
```

### 内置验证函数

- `ValidateNotEmpty` - 非空验证
- `ValidateFilePath` - 文件路径验证（检查文件是否存在）
- `ValidateDirPath` - 目录路径验证（检查目录是否存在）
- `ValidateNumber(min, max)` - 数字范围验证

## 🚀 快速开始

### 1. 基本使用

```go
package main

import (
    "fmt"
    "os"
    "github.com/lwdjd/IPFAR/internal/flags"
)

func main() {
    // 创建参数集合
    fs := flags.NewFlagSet("myapp")
    
    // 定义参数
    fs.DefineString("name", "n", "World", "名字", false)
    fs.DefineBool("verbose", "v", false, "详细模式")
    fs.DefineInt("port", "p", 8080, "端口号")
    
    // 解析参数
    if err := fs.Parse(); err != nil {
        fmt.Fprintf(os.Stderr, "错误：%v\n", err)
        os.Exit(1)
    }
    
    // 获取参数值
    name := fs.GetString("name")
    verbose := fs.GetBool("verbose")
    port := fs.GetInt("port")
    
    fmt.Printf("Name: %s, Port: %d, Verbose: %v\n", name, port, verbose)
}
```

## 🔧 API 参考

### 创建参数集合
```go
fs := flags.NewFlagSet("应用名称")
```

### 定义参数
```go
// 字符串
fs.DefineString(name, short, defaultValue, usage, required)

// 布尔
fs.DefineBool(name, short, defaultValue, usage)

// 整数
fs.DefineInt(name, short, defaultValue, usage)

// 高级（带验证）
fs.Define(Flag{...})
```

### 获取参数值
```go
value := fs.GetString(name)
value := fs.GetBool(name)
value := fs.GetInt(name)
```

### 检查参数状态
```go
if fs.IsSet("config") {
    // 用户指定了 config 参数
}
```

### 解析参数
```go
if err := fs.Parse(); err != nil {
    fmt.Fprintf(os.Stderr, "错误：%v\n", err)
    os.Exit(1)
}
```

## 📝 最佳实践

### 1. 使用有意义的默认值
```go
// ✅ 推荐
fs.DefineInt("port", "p", 8080, "端口号")

// ❌ 避免
fs.DefineInt("port", "p", 0, "端口号")
```

### 2. 为常用参数提供短名称
```go
fs.DefineString("config", "c", "config.json", "配置文件", false)
fs.DefineBool("verbose", "v", false, "详细模式")
```

### 3. 添加参数验证
```go
fs.Define(flags.Flag{
    Name:     "port",
    Value:    "8080",
    Usage:    "端口号",
    ValidateFunc: flags.ValidateNumber(1, 65535),
})
```

### 4. 错误处理
```go
if err := fs.Parse(); err != nil {
    fmt.Fprintf(os.Stderr, "错误：%v\n\n", err)
    fmt.Println("使用 -h 查看帮助信息")
    os.Exit(1)
}
```
